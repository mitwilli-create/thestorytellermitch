# Durable Agent Launch Brief Lab

An independent, source-linked product communications work sample for Vercel's Product Communications Manager, OSS role.

## What it proves

- One technical release claim adapted for four audiences without changing the underlying truth.
- A reproducible proof path that pairs product narrative with operational evidence.
- A static, inspectable artifact that deploys directly to Vercel without a build step or external dependency.

## Run locally

```sh
python3 -m http.server 8080
```

Open `http://localhost:8080`.

## Deploy

```sh
vercel --prod
```
