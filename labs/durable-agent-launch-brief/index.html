AI SDK 7 / WorkflowAgent

Agents can survive the pause.

A product launch signal lab for one technical truth: durable execution changes an agent from a live process into work that can pause, recover, and resume under human control.

The release claim
Durability is an operating contract, not an autonomy slogan.

WorkflowAgent can persist tool calls as workflow steps, retry from a failed step, and suspend for approval. The value is not that an agent does more without people. The value is that state, recovery, and intervention become explicit.

Change the reader, keep the truth

One release, four entry points

Show me the execution contract.

Lead with persisted steps, retry boundaries, approval semantics, observability, migration constraints, and failure modes. The abstraction earns trust when it composes cleanly with existing tools.

The proof path

What ships beside the announcement

01 / Reproduce

A runnable approval pause

Show one agent suspending for a human decision, surviving a refresh, and resuming without replaying completed work.

02 / Inspect

State and failure boundaries

03 / Decide

Does it belong in the stack?

Give the developer enough product truth to compare the durability model with the operational risk of a custom state machine.
