Reproduce the run

Use Python 3.10 or newer and the source revision below. The scorer uses the standard library. Both commands use the repository's synthetic fixtures.

git clone https://github.com/mitwilli-create/voice-os.git
cd voice-os
git checkout 991d8e8d0c6ec394286a1cc2db01c620db7e50cf
VOICE_OS_OFFLINE=1 python3 score.py \
  --corpus data/sample_corpus.txt \
  --draft data/sample_draft.txt --json
VOICE_OS_OFFLINE=1 python3 pipeline.py \
  --corpus data/sample_corpus.txt \
  --banned-list data/banned_list.txt \
  --draft data/sample_draft.txt \
  --output output/scored_draft.json

The scorer should exit 0. The second command should exit 1 and write the rejected result. Offline mode prevents live model calls. No key or personal corpus is required.
